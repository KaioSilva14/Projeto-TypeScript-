# Gerenciador de Despesas

## O que é

O Gerenciador de Despesas é um projeto desenvolvido em TypeScript para registrar entradas e saídas financeiras. O sistema armazena as transações em um array, calcula o total de entradas, o total de saídas e o saldo atual, além de permitir a filtragem dos lançamentos por categoria.

## Como executar

### 1. Instalar as dependências

No terminal, dentro da pasta do projeto, execute:

```bash
npm install
```

### 2. Executar o projeto

Para executar o código TypeScript, use:

```bash
npm run dev
```

O programa exibirá as transações cadastradas, o resumo financeiro e os lançamentos filtrados por categoria.

### 3. Compilar e executar o JavaScript

Para compilar o projeto, execute:

```bash
npm run build
```

Depois, execute a versão compilada com:

```bash
npm start
```
